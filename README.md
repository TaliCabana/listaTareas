# ✅ Lista de tareas 📝

Este proyecto permite al usuario ingresar tareas a una lista interactiva. Cada tarea agregada puede ser eliminada de forma individual con un botón. Está desarrollado con JavaScript y Bootstrap.

## Demo del proyecto

Mirá la demo del proyecto [aquí](https://listatareastali.netlify.app/) 👀

### 🔧 Tecnologías utilizadas 🛠
- HTML5
- CSS3
- JavaScript - ECMAScript 2025
- [Bootstrap v5.3](https://getbootstrap.com/)

### 🧠 Conceptos aplicados
- Manipulación del DOM
- Eventos y (`addEventListener`)
- Funciones
- Condicionales `if-else`
- Objetos y clases (`class`)
- Métodos y encapsulamiento con `#`
- Eventos y `addEventListener`
- Crear y eliminar elementos del DOM con createElement y removeChild
- Formularios y validación de inputs

## Cómo ejecutar el proyecto 💻

1. Cloná el repositorio escribiendo en una terminal el siguiente comando:  
   `git clone https://github.com/TaliCabana/listaTareas.git`
2. Luego abrí el archivo `index.html` con tu navegador preferido
